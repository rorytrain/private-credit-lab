Day 6. Stress tested all three analytical phases against deliberately malformed inputs: a CIM with no financial disclosure, a borrower update with contradictory leverage figures and a credit agreement that deferred all covenant terms to an absent side letter.

Phase 1 confirmed that the model scores a deal even when critical fields are null. Project Ghost received a score of 2 with EBITDA and facility returning null. The model flagged the data quality issues correctly but did not refuse to score. A production system needs a minimum data threshold gate before the prompt is assembled.

Phase 2 produced the most operationally dangerous result. The compliance monitor extracted leverage at 3.2x from a document containing two contradictory figures: 3.2x unaudited and 4.9x audited and restated. The compliance check would have passed on the extracted figure. The conflict was flagged correctly but the extracted value was the more favourable and less reliable number. Prompting can surface the conflict. It cannot determine which figure is authoritative. That requires source data provenance controls and auditor sign-off before figures enter the pipeline.

Phase 3 revealed a subtle but critical failure mode. In isolation the model correctly set covenants_found=false when instructed to be concise. In the full three-phase run it reverted to covenants_found=true, inferring covenant existence from a reference to an absent side letter. That inconsistency across runs at temperature zero is itself a finding: variance is reduced but not eliminated when prompt framing is ambiguous. A production system must validate covenant completeness independently of the model's own flag.

The cross-cutting failure modes, secrets management, orchestrator trust and audit trail integrity, cannot be addressed by prompt refinement. They require engineering controls, process discipline and infrastructure. The secrets management failure was not theoretical in this lab, it happened twice and required: two key rotations, a history rewrite and a GitHub support ticket to remediate.
